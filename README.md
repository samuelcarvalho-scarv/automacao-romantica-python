# Automação Romântica com Python ❤️

## Sobre o projeto

Este projeto foi desenvolvido como uma surpresa para minha esposa e como exercício prático durante meus estudos de programação em Python.

A automação utiliza comandos de mouse e teclado para executar uma sequência de ações no Windows, incluindo abrir o navegador, acessar o YouTube, reproduzir uma música, abrir uma imagem e escrever uma mensagem personalizada no Bloco de Notas.

## Tecnologias utilizadas

- **Python** — linguagem principal.
- **PyAutoGUI** — automação do mouse e teclado.
- **Pyperclip** — manipulação da área de transferência.
- **Time** — controle de intervalos entre as ações.

## Como executar

1. Ter Python instalado no Windows.
2. Instalar as dependências:

   `pip install pyautogui pyperclip`

3. Ajustar as coordenadas e os caminhos necessários para o computador utilizado.
4. Executar o arquivo `automacao_romantica.py`.

## Limitações

Este projeto utiliza coordenadas fixas para interagir com a interface gráfica. Por isso, seu funcionamento depende da resolução da tela, da posição das janelas e dos aplicativos instalados.

Também utiliza tempos de espera definidos manualmente, que podem precisar de ajustes conforme o desempenho do computador e a conexão com a internet.

## Aprendizados

Com este projeto, pratiquei:

- Importação e utilização de bibliotecas Python.
- Automação de tarefas no Windows.
- Simulação de cliques e digitação.
- Manipulação da área de transferência.
- Organização de uma sequência de comandos.
- Controle do tempo de execução.
